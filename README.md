# Privena - Personal Data Manager Mobile App

**Privena - Personal Data Manager Mobile App** is an Android note-taking and personal data management application developed using **Android Studio** with **Java** as the programming language.

Privena allows users to securely manage and organize personal notes through an authenticated mobile environment. **Firebase Authentication** is used to manage user access, while **Realm Database** is used to store and manage notes locally on the device.

## 👤 About the Project

**Privena** was developed as a personal note and data management solution for Android devices.

The application provides authenticated access to personal notes, allowing users to create, view, update, and manage their information through a structured and intuitive mobile interface.

User authentication is handled through Firebase, while Realm provides local data persistence, enabling notes to remain available on the device and efficiently organized within the application.

Privena combines cloud-based authentication with local data storage to provide a simple and structured approach to managing personal information.

## 🔐 Authentication

Privena uses **Firebase Authentication** to manage user identity and application access.

Authentication ensures that access to the application is associated with an authenticated user before personal notes and information can be managed.

This provides a clear separation between user authentication and local data management within the application.

## 🗃️ Local Data Management

Personal notes and application data are stored locally using **Realm Database**.

Realm provides persistent local storage, allowing note data to remain available on the device while supporting efficient data organization, retrieval, and updating.

The use of Realm enables Privena to maintain structured personal data without requiring note information to be continuously stored in a remote database.
