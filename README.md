# Personal Data Manager Mobile App

**Personal Data Manager Mobile App** is an Android note-taking application developed using **Android Studio** with **Java** as the programming language.

The application allows users to securely manage and organize personal notes through an authenticated mobile environment. **Firebase Authentication** is used to manage user access, while **Realm Database** is used to store and manage notes locally on the device.

## 👤 About the Project

Personal Data Manager Mobile App was developed as a personal note management solution for Android devices.

The application provides authenticated access to personal notes, allowing users to create, view, update, and manage their information through a structured mobile interface.

User authentication is handled through Firebase, while Realm provides local data persistence, enabling notes to remain available on the device and efficiently organized within the application.

## 🔐 Authentication

The application uses **Firebase Authentication** to manage user identity and access.

Authentication ensures that application access is associated with an authenticated user before personal notes can be managed.

## 🗃️ Local Data Management

Personal notes are stored locally using **Realm Database**.

Realm provides persistent local storage for note data, allowing information to remain available on the device while supporting efficient data organization and retrieval.
